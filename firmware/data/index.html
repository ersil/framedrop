    Add photos

    Each photo is shrunk to 1920 px on its long edge and saved as a JPEG before it is sent. Several photos go in as one batch, and the frame refreshes once when the last one is done.

    Saving to /. On a computer you can also drop photos onto this page.

    Queue

    Frame connection

    Checking…

    The drive stays connected while photos upload, so the slideshow keeps playing. When a batch ends, the frame is told the card changed and picks up the new photos.

    If the slideshow has stopped, this restarts the device. The frame sees the drive plugged in again and starts playing. It takes about 10 seconds.

    Wi-Fi

    Saving restarts the frame adapter, and it rejoins on the new network. This page is then at photoframe.local.

    Web login

    Viewing, uploading and deleting photos, settings and updates need this login. The page itself and the status line are open to anyone on the home network. The device keeps only a SHA-256 hash of the password.

    About

    An ESP32-S3 plugged into the frame's USB port. To the frame it looks like a USB drive backed by a microSD card; over Wi-Fi it serves this page.
